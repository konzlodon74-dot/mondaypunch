## What it does

`main.py` (Python 3, no network, no dependencies) writes one original joke
about Monday mornings to `/output/entry.txt`.

## The joke

> Monday walked in wearing a suit, introduced itself as the new boss, and HR still hasn't corrected it.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Output is deterministic: repeated runs produce byte-identical files.
